# Ejercicios

## 1) Puntuación del campeonato de fútbol

Nuestro equipo de fútbol terminó el campeonato.  
Los resultados de los partidos están registrados en una colección de *strings*. Cada partido está representado por un texto con el formato `"x:y"`, donde `x` es el marcador de **nuestro** equipo y `y` el marcador del **rival**.

**Ejemplo:** `["3:1", "2:2", "0:1", ...]`

La asignación de puntos por partido es:

- si `x > y`: **3 puntos** (victoria)  
- si `x < y`: **0 puntos** (derrota)  
- si `x = y`: **1 punto** (empate)

Escribir una función que tome esta colección y devuelva el **total de puntos** que obtuvo nuestro equipo (`x`) en el campeonato según las reglas indicadas.

**Notas**

- nuestro equipo siempre juega **10** partidos en el campeonato  
- `0 <= x <= 4`  
- `0 <= y <= 4`

**Ejemplo**


## 6) Cuadrado perfecto más cercano

La tarea es encontrar el **cuadrado perfecto más cercano** a un entero positivo `n`. En matemática, un **cuadrado perfecto** es un entero que es el cuadrado de otro entero (el producto de un entero por sí mismo).

- Ejemplo: si `n = 111`, el cuadrado perfecto más cercano es `121`, ya que `111` está más cerca de `121 (= 11^2)` que de `100 (= 10^2)`.
- Si `n` ya es un cuadrado perfecto (p.ej. `144`, `81`, etc.), simplemente devuelve `n`.

## 7) ¿Forman una terna pitagórica?

Dado un vector **no ordenado** de 3 enteros positivos `[n1, n2, n3]`, determinar si es posible formar una **Terna Pitagórica** con esos 3 enteros.

Una **Terna Pitagórica** consiste en acomodar 3 enteros tales que:

\na^2 + b^2 = c^2\n

**Ejemplos**

- `[5, 3, 4]` → es posible: `3^2 + 4^2 = 5^2`  
- `[3, 4, 5]` → es posible: `3^2 + 4^2 = 5^2`  
- `[13, 12, 5]` → es posible: `5^2 + 12^2 = 13^2`  
- `[100, 3, 999]` → **NO** es posible; no hay forma de satisfacer `a^2 + b^2 = c^2`

**Valor de retorno (Python):** `True` o `False`.

## 11) (Material teórico) Colinealidad de vectores

Dados dos vectores que parten del **origen** `(x=0, y=0)` con coordenadas `(x1, y1)` y `(x2, y2)`. Se solicita determinar si estos vectores son **colineales**. Los vectores colineales se encuentran sobre la **misma recta**; pueden estar dirigidos en el mismo o en sentido opuesto. Un vector puede obtenerse del otro multiplicándolo por un cierto número `k`. En coordenadas, los vectores `(x1, y1)` y `(x2, y2)` son colineales si existe `k` tal que:

\[(x1, y1) = (k \cdot x2, \; k \cdot y2)\]

**Imagen de referencia:**  
![Vectores colineales](https://d138zd1ktt9iqe.cloudfront.net/media/seo_landing_files/collinear-vectors-1627481628.png)  

### Descripción del problema

Escribir la función `collinearity(x1, y1, x2, y2)`, que devuelve un **booleano** según los vectores sean colineales o no.

**Condiciones**

- todas las coordenadas son enteras  
- `-1000 <=` cualquier coordenada `<= 1000`

**Notas**

- Todos los vectores comienzan en el origen `(0, 0)`.  
- Ten cuidado con casos donde `x1`, `x2`, `y1` o `y2` sean cero para evitar divisiones por cero.  
- El vector `(0, 0)` es colineal con **todos** los vectores.

**Ejemplos**

```
(1, 1, 1, 1)   ➞ true
(1, 2, 2, 4)   ➞ true
(1, 1, 6, 1)   ➞ false
(1, 2, -1, -2) ➞ true
(1, 2, 1, -2)  ➞ false
(4, 0, 11, 0)  ➞ true
(0, 1, 6, 0)   ➞ false
(4, 4, 0, 4)   ➞ false
(0, 0, 0, 0)   ➞ true
(0, 0, 1, 0)   ➞ true
(5, 7, 0, 0)   ➞ true
```
